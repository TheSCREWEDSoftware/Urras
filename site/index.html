Urras

A fast, native Git client for Windows and Linux. Free and open source.

Download → View on GitHub →

Windows (.zip) and Linux (.tar.gz), one file with nothing else to install.

What it does

All your repositories

Grouped by name with their forks, by folder, by owner or by hand. Pin, search (Ctrl+F) and import everything from a folder or from GitHub Desktop in one go.

Changes, line by line

Stage, unstage or discard single lines or hunks. Unified, split or raw diffs with syntax colours, word-level highlights, Markdown rendered and images compared.

History and the past

A commit graph across every branch, blame, file history, searching commits, comparing commits and branches, and the reflog for finding lost work.

The big Git jobs

Merge, rebase and interactive rebase, a conflict resolver you can edit, bisect, stashes, tags, submodules, worktrees and Git LFS.

GitHub, GitLab and more

Accounts on GitHub, GitLab, Gitea, Codeberg and Bitbucket: pull requests, notifications, profile pictures, co-authors by @username, and forks that know where changes go.

Quick and careful

Native, not a web page in a window. Refreshes when something changes, asks before anything that can lose work, and keeps a daily backup of its settings.
